# 🚀 Google Antigravity Mobile Workspace

This workspace hosts the mobile companion clients for **Google Antigravity**:

1. **[Antigravity Native App](./Antigravity%20Native%20App/)**: 
   - 100% Pure Native Android App built with **Kotlin**, **Jetpack Compose**, **Material 3**, **Coroutines & Flow**, **OkHttp WebSockets**, and **CameraX QR Scanner**.
   - Zero WebView overhead, 120 FPS animations, native haptics, low memory footprint.

2. **[Antigravity WebView App](./Antigravity%20WebView%20App/)**: 
   - Progressive Web App (PWA) & Hybrid Android App built with **React**, **Vite**, **Tailwind CSS**, and **Capacitor**.
   - Includes standalone desktop WebSocket bridge server (`server/bridge.cjs`).
